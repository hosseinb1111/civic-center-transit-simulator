About the data. Illustrative mode uses synthetic departures and passenger demand. Real schedule mode can be enabled by importing official BART and SFMTA GTFS static feeds. Static GTFS is scheduled service, not real-time train tracking. Passenger movement and dwell behavior remain simulated in both modes. This project is not affiliated with BART or SFMTA.

Keyboard: Space pauses or resumes. Keys 1, 2, 4 and 8 set speed. All controls can also be reached using Tab and activated with Enter or Space.
